Deployment smoke test for the GPU CodeCheck instance. Write a function sum_of_doubles(n) that:

  • builds the array 0, 1, 2, …, n-1,
  • doubles every element using a numba.cuda kernel, and
  • returns the sum of the doubled array as an int, computed with CuPy on the device.

For example, sum_of_doubles(8) returns 56 and sum_of_doubles(100) returns 9900.

If this problem checks green, numba-cuda kernel launches, host/device transfers, and CuPy reductions all work in the deployed comrun-gpu.
